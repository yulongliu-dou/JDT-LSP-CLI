有价值的组合命令（多个 LSP 功能合并为单次调用）
jls safe-rename
语义级安全重命名。先 prepareRename 检查可行性，再 rename 获取 WorkspaceEdit，最后 diagnostics 验证无编译错误，一步完成。
prepareRename rename diagnostics
jls where
语义搜索替代 grep。输入符号名，返回所有真实引用（按类型分：方法调用/字段读/字段写），不含字符串和注释中的同名词。
semanticTokens references documentHighlight
jls impact
改动影响分析。给定一个方法，返回：直接调用者、跨模块引用数、相关测试类、是否被接口/抽象类声明。帮助 agent 评估改动风险。
references callHierarchy implementations codeLens
jls explain
方法语义摘要。聚合 hover（文档）、inlayHint（推断类型）、codeLens（引用数）、typeDefinition，一次返回 agent 理解方法所需的全部元数据。
hover inlayHint codeLens typeDefinition
jls edit-verify
编辑后验证。agent 写入代码修改后，立即拉取 diagnostics + semanticTokens，确认无编译错误，且新引入的标识符类型符合预期。形成编辑闭环。
diagnostics semanticTokens codeAction
jls type-context
类型上下文探查。给定变量或表达式，返回：推断类型、类型定义位置、该类型的可用方法列表（来自 completion）。agent 写调用链时使用。
inlayHint typeDefinition completion hover
